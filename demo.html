Example university page

Stand-in for a university page rendered by TYPO3. The launcher in the bottom-right corner is created by the shipped widget loader from a .studi-assist-chatbot-root element — the same element the Fluid template and the global TypoScript block emit. Every control on the left maps 1:1 to a plugin/constant setting; the generated TypoScript constants for the current state are shown in the panel, ready to paste into the Constant Editor.

Note: changing a setting rebuilds the widget (the real loader reads its configuration once at init), so an open chat window reloads its iframe.
